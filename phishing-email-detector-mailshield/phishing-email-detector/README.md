# 🛡️ MailShield: Phishing Email Detection with Machine Learning & NLP

A beginner-friendly cybersecurity Machine Learning project using **Python**, **Scikit-learn**, and **Natural Language Processing (NLP)**.

## Quick Start
```bash
git clone https://github.com/your-username/phishing-email-detector.git
cd phishing-email-detector
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python src/train_model.py
python src/predict.py
```
